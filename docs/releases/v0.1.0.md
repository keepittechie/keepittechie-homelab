# v0.1.0 Release Notes

v0.1.0 is the first public documentation baseline for the KeepItTechie homelab repo.

This milestone turns the repo into a public-safe learning resource for viewers who want to understand the homelab architecture, service layout, diagrams, examples, and safety boundaries without exposing private infrastructure details.

## What Is Included

- Public-safe README and navigation.
- Documentation index, viewer guide, glossary, and service-page reading guide.
- Service matrix for quick comparison across homelab services.
- Core infrastructure docs for firewall, DNS, virtualization, backups, reverse proxying, and selected public access.
- Storage, backup, and monitoring docs with restore test evidence guidance.
- App, media, local AI, dashboard, documentation, personal app, and automation deep dives.
- Mermaid diagrams for the major architecture flows.
- Sanitized configuration examples for common homelab patterns.
- Contribution guidance, PR/issue templates, screenshot policy, and repo settings guidance.
- Lightweight docs quality workflows and local scripts.

## Public-Safety Notes

This release uses sanitized examples such as:

```text
home.example.com
10.10.0.0/24
proxy.home.example.com
grafana.home.example.com
ai.home.example.com
```

The docs explain patterns without publishing real public IP addresses, exact private host IPs, private domains, credentials, private certificate material, tunnel identifiers, raw exports, screenshots, financial data, or career data.

## Intentionally Not Included

- Real firewall, router, NAS, or app exports.
- Real screenshots from private dashboards or admin panels.
- Live DNS zones or exact host inventories.
- Private `.env` files or runtime config.
- Real restore test screenshots or private restore logs.
- Future guide pages that have not been written yet.

## Next Planned Improvements

- Expand learning paths as new public-safe guides are added.
- Add sanitized screenshots or demo dashboard images after screenshot review.
- Add restore test evidence for selected services using public-safe notes.
- Expand sanitized config examples where they teach a clear pattern.
- Continue improving beginner explanations based on viewer questions.
