# Monitoring

## Purpose

Monitoring provides visibility into server health, container health, logs, and uptime.

## Stack

- Grafana
- Prometheus
- Node Exporter
- cAdvisor
- Blackbox Exporter
- Speedtest exporter
- Loki
- Promtail
- Proxmox exporter

## Document

- Dashboard screenshots
- Exporter targets
- Alert rules
- Log sources
- Backup location for dashboards
