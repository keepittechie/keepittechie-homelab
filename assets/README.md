# Assets

This folder is reserved for future public-safe visual assets for the KeepItTechie homelab repo.

No real screenshots or dashboard images are included yet. Any future image added here should pass the screenshot and visual review checklist before commit.

## Planned Folders

| Folder | Purpose |
|---|---|
| `assets/diagrams/` | Exported public-safe diagrams |
| `assets/screenshots/` | Reviewed screenshots or demo screenshots |
| `assets/thumbnails/` | GitHub or social preview images |
| `assets/mockups/` | Recreated UI mockups and fake-data visuals |

## Rules Before Adding Images

- Review the image at full size.
- Confirm there are no real IP addresses, private domains, usernames, emails, secrets, tunnel IDs, or private data.
- Prefer fake/demo data over live dashboard captures.
- Crop or blur anything that is not needed for the teaching point.
- Link the visual to the relevant doc so it has context.
