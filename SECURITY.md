# Security Policy

This repo is public-facing homelab documentation.

## Reporting Sensitive Data

If you notice a leaked secret, credential, token, private IP that should not be public, or sensitive config, open a private channel with the repo owner immediately.

## Never Commit

- Passwords
- API keys
- VPN keys
- Cloudflare tunnel credentials
- Private certificates
- Full firewall exports
- Real `.env` files
