## [0.1.0] - 2026-06-17

### Added

- Public-safe README and beginner navigation for KeepItTechie viewers.
- Documentation index, viewer guide, glossary, and service-page reading guide.
- Service matrix for comparing service purpose, access level, host role, and backup priority.
- Core infrastructure docs for pfSense, Pi-hole, Proxmox, Proxmox Backup Server, reverse proxy, and Cloudflare Tunnel.
- Storage, backup, and monitoring docs covering Synology NAS, Linux ZFS storage, restore test evidence, Grafana, Prometheus, Loki, and exporters.
- App, media, local AI, dashboard, documentation, personal app, and automation service docs.
- Public-safe Mermaid diagrams for the homelab overview, DNS flow, backup flow, reverse proxy flow, local AI flow, and monitoring flow.
- Sanitized configuration examples for NGINX, Docker Compose, Prometheus, Pi-hole local DNS, Cloudflare Tunnel, and environment files.
- Contribution guidance, pull request template, issue templates, screenshot policy, and GitHub repo settings guidance.
- Lightweight docs quality workflows and local scripts for Markdown links, diagram structure, public-safety checks, and whitespace checks.
